Sistem Pendukung Keputusan Pemilihan Kereta Api Terbaik (Rute Jakarta - Yogyakarta) dengan Metode AHP Berbasis Streamlit   Sebuah aplikasi Sistem Pendukung Keputusan (SPK) berbasis web yang dirancang untuk membantu calon penumpang menentukan jadwal kereta api paling optimal dari Stasiun Pasar Senen (PSE) menuju Stasiun Yogyakarta (YK) atau Lempuyangan (LPN).  Aplikasi ini mengimplementasikan algoritma Analytical Hierarchy Process (AHP) untuk melakukan pembobotan kriteria secara objektif berdasarkan preferensi pengguna. Analisis keputusan didasarkan pada 5 kriteria utama, yaitu Biaya (Harga Tiket), Jenis Rangkaian (Fasilitas/Kenyamanan), Waktu Sampai, Waktu Tempuh, dan Jumlah Stasiun Pemberhentian.  Fitur Utama:
* Interactive Data Filtering: Memilih stasiun tujuan (YK/LPN) dan menyaring kelas kereta (Ekonomi/Eksekutif) secara real-time.
* Dynamic Pairwise Comparison Matrix: Input matriks perbandingan berpasangan antar kriteria dengan skala Saaty (1-9) secara fleksibel.
* Automated Consistency Check: Perhitungan otomatis untuk Consistency Index (CI) dan Consistency Ratio (CR) guna memastikan logika penilaian pengguna konsisten ($CR \le 0.1$).
* Automated Alternative Evaluation: Pembuatan matriks perbandingan alternatif secara otomatis berdasarkan data aktual (skor cost dan benefit).
* Sintesis Akhir & Visualisasi: Menampilkan rekomendasi peringkat kereta terbaik menggunakan grafik dan tampilan kartu yang intuitif.
